# NMS Ansible Deployment Documentation

This folder contains the deployment and project reference documents for the NMS Ansible environment.

## Documentation

| Document | Description | PDF |
|---|---|---|
| Client Requirements Sheet | Information to collect from the client and where each value is configured in the project. | [View PDF](Client_Requirements_Sheet.pdf) |
| Ansible Deployment Runbook | Step-by-step procedure for preparing the Ansible controller and deploying the project. | [View PDF](Professional_Ansible_Deployment_Runbook.pdf) |
| RKE2 Kubernetes Cluster Deployment Guide | On-premises RKE2 cluster deployment guide using KVM/libvirt, three master nodes, three worker nodes, and HAProxy. | [View PDF](RKE2_Kubernetes_Cluster_Deployment_Guide.pdf) |
| Project Reference Guide | Plain-English explanation of the project folders, files, playbooks, and roles. | [View PDF](What_Every_File_Does_Project_Guide.pdf) |

## How to use

1. Open the PDF link for the document you need.
2. Download the PDF if you need an offline copy.
3. Use the Word (`.docx`) source files when editing or updating the documentation.

## Repository layout

```text
Documents/
```
